Las reglas se escriben en público.

Cada regla es una RFC de una carilla: qué se propone, quién objetó, cómo se resolvió. Se discuten en el pull request que las propone y se pueden comentar antes de anotarse. Las que están abiertas son las decisiones que faltan.
